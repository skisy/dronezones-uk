# Drone Zones UK data files

`nature-sites.json.gz` lists the UK's protected nature sites (SSSIs in England, Scotland and Wales; ASSIs in Northern
Ireland), for the Drone Zones UK app. It's built by `DroneZones.Check --build-nature` from the agencies' open data,
with boundaries simplified to about 5 m. It's for information: the agencies' own maps are the authoritative source.
